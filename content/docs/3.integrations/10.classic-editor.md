Since the inception of WordPress, the [Classic Editor](https://wordpress.org/plugins/classic-editor/) has been the default editor for WordPress. Despite introducing [Gutenberg](/docs/integrations/gutenberg) as the new default editor, the Classic Editor is still widely used by many WordPress users and developers.

## How to use custom fonts in the Classic Editor

In the Classic Editor, you can use any fonts you have [added](/docs/fonts/custom-font) to Yabe Webfont.

### Step 1: Toggle the toolbar

On the WYSIWYG editor, click the :icon{name="lucide:layout-grid"} icon to toggle the toolbar.

![Toggle the toolbar](/tutorial/integration/classic-editor/1.png)

### Step 2: Select the font family

Open the **Font Family** dropdown list, and select the font family you want.

![Select the font family](/tutorial/integration/classic-editor/2.png)
