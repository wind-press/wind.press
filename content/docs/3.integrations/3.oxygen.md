[Oxygen](https://oxygenbuilder.com/) is the ultimate visual site builder for WordPress & WooCommerce. Use Oxygen's unparalleled power, flexibility, and light-weight code to visually design your WordPress or WooCommerce site with ease.

Yabe Webfont is fully featured and working great with Oxygen. The built-in integration gives you the native experience of using custom fonts in Oxygen.

## Using custom fonts in the Oxygen

You can use any [Custom Font](/docs/fonts/custom-font), embedding [Adobe Fonts](/docs/fonts/adobe-fonts) or [self-hosting Google Fonts](/docs/fonts/google-fonts) in the Oxygen and cross-platform.

### Step 1: Choose the text element

Choose the text element by clicking on the canvas or the Structure panel.

![Choose the text element in Oxygen](/tutorial/integration/oxygen/1.png)

### Step 2: Switch to the Advanced tab

On the Element panel, click on the **Advanced** tab.

![Switch to the Advanced tab](/tutorial/integration/oxygen/2.png)

### Step 3: Open the Typography panel

Click the **Typography** menu to expand the panel.

![Open the Typography panel](/tutorial/integration/oxygen/3.png)

### Step 4: Choose the font

Click the **Font family** dropdown field to open the list, and select the font family with the badge **Yabe**.

![Choose the font family](/tutorial/integration/oxygen/4.png)

## Disable the Google Fonts in Oxygen

Oxygen use the Google Fonts Web API to provide users with the Google Fonts collection. To be GDPR compliant, you must disable the Google Fonts in Oxygen.

Yabe Webfont forcibly programmatically disables the Google Fonts in Oxygen, so you don't need to do anything.
