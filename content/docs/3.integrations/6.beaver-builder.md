[Beaver Builder](https://www.wpbeaverbuilder.com/) A drag and drop frontend WordPress page builder plugin that works with almost any theme!

## How to use custom fonts in the Beaver Builder

You can use any [Custom Font](/docs/fonts/custom-font), embedding [Adobe Fonts](/docs/fonts/adobe-fonts) or [self-hosting Google Fonts](/docs/fonts/google-fonts) in the Beaver Builder easily.

### Step 1: Choose the text element

Choose the text element by clicking on the canvas or the Structure panel.

![Choose the text element in Beaver Builder](/tutorial/integration/beaver-builder/1.png)

### Step 2: Switch to the Style tab

On the Element panel, click on the :icon{name="lucide:palette"} icon to switch to the **Style** tab.

![Switch to the Style tab](/tutorial/integration/beaver-builder/2.png)

### Step 3: Open the Typography panel

Click the **Typography** menu to expand the panel.

![Open the Typography panel](/tutorial/integration/beaver-builder/3.png)

### Step 4: Choose the font

Click the **Font family** dropdown field to open the list, and select the font family from the **System** group list.

![Choose the font family](/tutorial/integration/beaver-builder/4.png)

## Disable the Google Fonts in Beaver Builder

Beaver Builder uses the Google Fonts Web API to provide users with the Google Fonts collection. To be GDPR compliant, you must disable the Google Fonts in Beaver Builder.

Yabe Webfont forcibly programmatically disables the Google Fonts in Beaver Builder, so you don't need to do anything.
