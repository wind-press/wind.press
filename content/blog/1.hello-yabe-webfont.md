Today we are so excited to announce that Yabe Webfont is officially released! 🎉

**Yabe Webfont** is a new kind of [WordPress](https://wordpress.org/){target="_blank"} plugin that reimagined how you can manage fonts in WordPress. It is designed to be GDPR-friendly, easy to use, and packed with features that streamline your workflow.

![](/blog/hello-yabe-webfont.jpg)

---

## 🔒 GDPR Compliance: Why It Matters

In January 2022, a German court ruled that loading Google Fonts from Google's servers violates GDPR because it transmits user IP addresses without consent. This created an urgent need for WordPress users to self-host their fonts.

:icon{name="fa6-solid:triangle-exclamation" class="mr-1.5"} The most common challenges faced by WordPress users include:

- **GDPR / DSGVO compliance** — Google Fonts hosted on Google's servers transmit user IP addresses and user agents.
- **No unified font manager** — WordPress has no built-in way to manage custom fonts across themes and page builders.
- **Complex setup** — Self-hosting fonts manually requires FTP access, CSS knowledge, and ongoing maintenance.

---

## 🚀 The Complete Font Management Solution

Yabe Webfont solves these problems — and much more. It's not just a Google Fonts self-hosting plugin. It's a complete font management solution for WordPress.

:icon{name="fa6-solid:wand-magic-sparkles" class="mr-1.5"} Import Google Fonts with one click, embed Adobe Fonts via Project ID, or upload your own custom font files — all without touching a single line of code.

---

## 🔥 Features That Streamline Your Workflow

Yabe Webfont is packed with features designed for designers and developers:

- :icon{name="fa6-solid:shield-halved" class="mr-1.5"} **GDPR / DSGVO friendly** — Self-host Google Fonts locally on your server. No external requests.
- :icon{name="fa6-solid:cloud-arrow-down" class="mr-1.5"} **Google Fonts ready** — One-click import of 1,500+ Google Fonts families with subset selection and variable font support.
- :icon{name="fa6-solid:paintbrush" class="mr-1.5"} **Adobe Fonts embedding** — Sync your Adobe Fonts Web Projects via Project ID.
- :icon{name="fa6-solid:cloud-arrow-up" class="mr-1.5"} **Custom fonts upload** — Upload your own font files via the WordPress media uploader. No FTP required.
- :icon{name="fa6-solid:puzzle-piece" class="mr-1.5"} **12 visual builder integrations** — Native font selection in Elementor, Bricks, Oxygen, Breakdance, Gutenberg, and more.
- :icon{name="fa6-solid:code" class="mr-1.5"} **CSS custom properties** — Every font gets a CSS variable automatically: `--ywf--family-{slug}`.
- :icon{name="fa6-solid:sliders" class="mr-1.5"} **Variable fonts support** — Single file, multiple stylistic variations.
- :icon{name="fa6-solid:power-off" class="mr-1.5"} **No-plugin mode** — Fonts keep working even after disabling the plugin.
- :icon{name="fa6-solid:feather" class="mr-1.5"} **Lightweight and fast** — Built on the WordPress REST API with font preloading and front-page cache.
